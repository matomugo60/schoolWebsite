# Prestige University Website 
## Project Overview
A premium, responsive website for Prestige University built with HTML, CSS, and JavaScript. Designed to showcase the university's programs, faculty, campus life, and admissions information with an elegant, high-end aesthetic.

### Features
✅ Responsive Design - Fully mobile-friendly with hamburger menu
✅ Premium UI - Elegant color scheme (navy/gold) and typography
✅ Complete Sections:

Home hero with call-to-action

About the university

Academic programs

Faculty profiles

Tuition & financial aid

Campus activities

Contact form

✅ Interactive Elements:

Smooth scrolling navigation

Animated cards on scroll

Form validation

Mobile menu toggle

File Structure
prestige-university-website/
        ├── index.html          # Main HTML file
        ├── css/
        │   ├── style.css       # Main styles
        │   └── fonts.css       # Font imports
        ├── js/
        │   └── script.js       # All JavaScript functionality
        └── images/             # Image assets (add your own)
### Installation
Clone or download this repository

Open index.html in any modern browser

For development, use Live Server in VS Code or similar

Customization
To personalize:
Logo - Replace placeholder in header/footer

Images - Add your own to /images folder

Colors - Edit CSS variables in style.css:

css
      :root {
          --primary-color: #1a365d;    /* Navy blue */
          --secondary-color: #d4af37;  /* Gold */
          --accent-color: #5d1a1a;
          --light-color: #f8f9fa;
          --dark-color: #212529;
}
Content - Update text in index.html
